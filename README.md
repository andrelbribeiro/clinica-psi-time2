# Clinica-psi
Aponti - FAP - Teste de Software - Clinica Psi

Sistema front-end de gestão de clínica de psicologia criado em HTML, CSS e JavaScript puro. Os dados ficam no `localStorage` do navegador, portanto não requerem servidor.

## Deploy no GitHub Pages

1. Crie um repositório e envie todos os arquivos para a branch `main`.
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione `main` e a pasta `/(root)`, depois clique em **Save**.
5. O GitHub mostrará a URL pública após a publicação.

## Funcionalidades

Dashboard; pacientes; psicólogos; funcionários; perfis e permissões; especialidades; convênios; salas; agenda; agendamentos; reagendamentos; check-in; prontuários; evoluções; recibos; receitas; despesas; relatório financeiro; produtos; estoque; fornecedores/compras; indicadores.
